# Raw data location

Place original downloads here, for example:

- `uci_sms_spam/SMSSpamCollection`
- `phiusiil/PhiUSIIL_Phishing_URL_Dataset.csv`
- `hinglish_scam/` (only after overlap/provenance review)

Do not commit raw datasets to Git by default. Preserve each source's attribution/licence and download notes in `docs/data_sources.md` or a dataset manifest. Never place private user messages or secrets here.
